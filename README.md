# Anisotropic interactions induce dynamical spin freezing in artificial colloidal ice

Code for paper titled "Anisotropic interactions induce dynamical spin freezing in artificial colloidal ice"

## Installation

1. Clone the repository and `cd` into it
```
git clone https://github.com/leogabac/stuckgs.git --recurse-submodules
```
This will clone `leogabac/icenumerics`, `aortiza/magcolloids` (submodule) and change to the `dev` branch.


2. Create a virtual environment with `python 3.12.0` and install the contents of `requirements.txt`

```
virtualenv --python=$HOME/.pyenv/versions/3.12.0/bin/python3.12 .venv
source .venv/bin/activate
pip install -r requirements.txt
```
