Code for paper titled "Anisotropic interactions induce dynamical spin freezing in artificial colloidal ice"

> [!WARNING]
> The repository is in the process of cleaning. Some references to libraries might be broken.

## Installation

1. Create a virtual environment with `python 3.12.0` and install the contents of `requirements.txt`

```
virtualenv --python=$HOME/.pyenv/versions/3.12.0/bin/python3.12 .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Clone `leogabac/icenumerics` and `aortiza/magcolloids` and change to the `dev` branch.

```
cd stuckgs
git clone https://github.com/leogabac/icenumerics.git --recurse-submodules
cd icenumerics
git checkout -b dev origin/dev
```
