# Source Code

Here you will find all the source code.

## Used in the paper

* `parameters.py`: Contains a dictionary of (most) parameters for the simulations.
* `sims/`: Simulation scripts
* `auxnumerics/`: Auxiliary functions.
* `utils/`: Auxiliary cleaning and random scripts for data-handling.
* `fig-notebook`: Notebook that contain the figures of the paper (or at least the first versions)
